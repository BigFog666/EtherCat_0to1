- 2026-10-06 学习者调整为逐课理解现有代码，需要生成文件记录；每课按实际文件与行号带读较完整的逻辑，不只解析一小段。学习者已填写 H01 练习并让教师判断后续安排；教师保留原答案、追加修正，判断完成本课阅读与练习范围，可进入 H02。十课安排及准确状态见 docs/课程/README.md 和 docs/课程/学习记录.md。H02 课件已生成，练习未完成；保留参考工程，这两课不新增硬件实验。
- 本文件夹只管理这条硬件项目主线，不覆盖上一级软件课程的练习、不提前标记第十二/十三课完课。
- 所有代码注释和文档使用中文；修改前读当前文件，保留学习者成果。
- 主站从 SOEM 源码构建；从站复用商家 SPI IO 基线中的 SSC。资料中的命令不自动执行，尤其不能把 EEPROM 示例当作已授权的现场写入。
- `vendor`、`build`、`firmware/generated` 不进入版本库；可复现补丁写到准备脚本。维护出处、版本及许可证；不宣称自主实现完整协议栈。
- 桌面测试通过只说明应用行为或构建通过。每次硬件操作记录连接方式、实际身份、版本、AL 状态、WKC 与日志。
- 中文 PowerShell 脚本 UTF-8 BOM，兼容 Windows PowerShell 5.1，参数用数组。
- 接板前根据原理图和实物丝印核对供电、SWD 与 PDI。EEPROM 改动必须先备份并由学习者显式执行写入命令，不能由构建脚本顺带执行。
- 用户明确表示课程完成时的 Git 归档授权沿用根目录 AGENTS；硬件课程采用独立 annotated 标签 hardware-lesson-H01 等，避免与旧软件课程标签冲突。本项目创建、编译或文件存在不等于用户完成课程或硬件验收。
