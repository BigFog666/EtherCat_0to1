# 资料只按当前问题打开

完整目录与重要性整理已在 [商家资料阅读指南](../../docs/商家资料阅读指南.md)。本页按本硬件项目重新收窄：不用先读完几十份 PDF 才能开始。商家文档中的例程要求按其配套版本理解，不能直接作为当前项目配置。

## 接板前优先看

| 优先级 | 资料 | 这次只找什么 |
|---|---|---|
| 必看 | `03_EtherCAT开发板硬件相关/开发板原理图/EtherCAT开发板原理图V3.pdf` | 5V USB 供电、3V3 电平、BOOT0、SWD、STM32 到 LAN9252 的信号 |
| 必看 | `02_EtherCAT开发板说明文档/PDI接口配置-R1.1.xlsx` | SPI/HBI 配套设置、引脚和 EEPROM 配置；按实物核对 |
| 必看 | `02_EtherCAT开发板说明文档/烧写EEPROM的方法.pdf` | EEPROM 保存什么、备份和断电重启；实际本项目可用 SOEM 工具 |
| 必看 | 本项目运行手册及 `config/EtherCAT_Joint_F407.xml` | 固件身份、SDO 身份、SII 与 12/12 字节映射必须一致 |
| 按函数读 | `06_EtherCAT开发板源代码/EtherCAT_IO例程/IO例程_SPI_OLED+LED+KEY.zip` | 原厂 main/HW_Init、SPI、PDI ISR、应用映射，不要求逐行看完整 SSC |

本项目已选择标准库 SPI IO 包作为硬件驱动基线，打开其附带 CiA402 应用字典并替换应用模型。商家 HAL CiA402 包是另一套工程，其引脚、设备身份和 XML 不能混用。商家原理图与原工程型号字段也存在 ZG/ZE 差别，本项目按你确认的 ZET6 使用 512 KiB Flash 链接范围。

## 运行到哪里，再查哪里

| 现场问题 | 查什么 |
|---|---|
| ST-LINK 不识别或运行不到 main | V3 原理图、SWD/BOOT、STM32F4 调试及启动相关章节 |
| 卡在 HW_Init、BYTE_TEST 异常 | LAN9252 中文手册的 SPI/SQI、复位、EEPROM、CSR/PRAM；本项目 GDB 诊断变量 |
| 扫得到但 PREOP→SAFEOP 失败 | EtherCAT 诊断文档、实际 AL 错误码、SM/PDO 配置、本项目映射表 |
| SDO 失败 | `mailbox_help.txt`、`sdoserv.c` / `objdef.c`；先定位索引和错误信息 |
| 想增加变量 | 从站添加对象字典流程、ESI 规范、对应应用字典头文件 |
| 第一版已经稳定，想提同步性能 | DCIntroduction、通用 ESC 技术说明的 DC 章节、LAN9252 SYNC0；需实现并验证对应 IRQ |
