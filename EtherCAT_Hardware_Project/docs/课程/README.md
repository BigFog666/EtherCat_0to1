## 学习方式

每一节按“打开文件 → 定位代码 → 解释职责 → 跟随一次数据 → 对照现象 → 完成练习”进行。先能说明代码的输入、输出和调用位置，再要求修改或仿写。源码中的学习者修改要保留，编辑前先读取当前内容。

第 01 课只读已有源码和已保存的实测日志；不会重新接线、烧录、运行主站，也不会重构现有程序。后续修改以明确的小任务推进，不一次重写整套协议栈。

第一、二课以源码阅读、手算和历史日志为主；后面的硬件操作放到对应课题中，以明确的修改和观察目标推进。FreeRTOS、DC 同步、真实电机和 CST 作为完成主线后的选修方向，不要求在这十课中同时实现。H09 的接口扩展需按板端与主站匹配配置安排，不默认改写 EEPROM。

每课包含多个阅读站点、一条完整数据或状态路径、现象解释、练习和必要的参考答案。教师生成课件不等于学习者已完课；会核对你的解释，保留原答案，再追加修正。
