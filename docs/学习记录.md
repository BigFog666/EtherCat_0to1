## 第六课：PDO 与 Process Image，已完成

- 版本：`lesson-06`，建立 Git 时重建的完课归档。
- 理解 RxPDO/TxPDO 使用从站视角，以及主站输入/输出过程映像。
- 固定布局：RxPDO = 16 位控制字 + 32 位目标位置；TxPDO = 16 位状态字 + 32 位实际位置，各 6 字节。
- 使用显式小端打包/解包，避免依赖结构体填充或本机字节序。
- 学习者完成修改：目标位置 1000 → 2000；模拟实际位置 0 → 300。
- 学习节奏调整：先看懂、修改、运行，再逐步仿写；代码补充中文注释。
- 修正 PowerShell 构建脚本：参数数组替代反引号续行，中文脚本保留 UTF-8 BOM。
- 已验证：GCC 编译及运行、位置正负数和 int32_t 边界、小端布局；构建脚本在 Windows PowerShell 5.1 和 PowerShell 7 中验证。

完课运行的关键输出：

```text
Master outputs / Slave RxPDO: 00 00 D0 07 00 00
Slave received: controlword=0x0000, target_position=2000
Slave TxPDO / Master inputs: 00 00 2C 01 00 00
Master received: statusword=0x0000, actual_position=300
```

注意：简化 EtherCAT 状态切换只用于教学。尚未实现完整 ESC、EtherCAT 报文、CiA402 或电机模型。

## 第七课：对象字典，已完成

- 开始版本：`lesson-07-start`；完课版本：`lesson-07`。学习者于 2026-10-02 明确确认完课。
- 新增 ethercat_od.h / ethercat_od.c。
- 先支持两个 INTEGER32 对象：0x607A:00 目标位置（RW）、0x6064:00 实际位置（RO）。
- 字典保存已有从站变量的指针，PDO 与字典使用同一份位置数据。
- 通过索引和子索引查找对象，执行本地读取、写入、权限检查。
- 已验证：共享变量更新、只读写入拒绝、对象不存在、子索引不匹配和空指针处理。
- 练习已完成：学习者把字典写入值 2500 改成 4000；前面的 RxPDO 仍传目标位置 2000，反馈仍为 300。
- 针对 C 实现的阅读困难，先掌握函数输入、输出和共享变量的数据流，再逐步学习指针、查表和权限检查；不要求立即独立编写整个模块。

完课运行新增输出：


本课是本地查表和读写，尚未实现 Mailbox、CoE 报文或 SDO。下一课学习 SDO 如何访问对象字典。

## 第八课：Mailbox、CoE 与 SDO，学习中

- 开始版本：`lesson-08-start`，2026-10-02 开始，尚未完课。
- 第一步新增 ethercat_sdo.h / ethercat_sdo.c，仅模拟已解析的请求和响应。
- 理解 Mailbox 是消息机制、CoE 是一种邮箱协议、SDO 是对象读写服务、OD 是变量描述表。
- 区分 Upload（主站读取）和 Download（主站写入）；用邮箱空闲、请求就绪、响应就绪三个状态保护单笔事务。
- 保留此前练习：PDO 目标 2000、实际位置 300、字典本地写入 4000。新演示用 Download 写入 5000，再 Upload 读回，并拒绝写入实际位置。
- 当前代码没有实现实际 Mailbox/CoE/SDO 报文字节格式、标准 Abort Code、分段传输或超时重试，不能作为真实 EtherCAT 从站使用。
- 已验证：GCC 严格警告编译和运行、Windows PowerShell 5.1/7 构建、邮箱忙时不覆盖请求或响应、请求复制、失败响应、空指针、负数及 int32_t 边界读写。
- 练习进度：学习者已将 main 中本课写入值 5000 改为 6000；新写入及读回输出为 6000，前面的第六、七课输出不变。下一小步再学习实际报文字节格式，第八课仍未完课。
- 根据学习者建议补充 docs/程序运行流程图.md，展示 main 的阶段顺序、主站/从站模拟角色、一次 SDO 事务及目标变量变化；第八课仍在学习中。
