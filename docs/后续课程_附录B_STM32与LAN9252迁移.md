## 1. 对照软件与硬件边界

LAN9252 是含以太网 PHY 的 EtherCAT 从站控制器；MCU 通过所选 PDI 访问它。产品和 SPI 示例见 [Microchip 产品资料](https://www.microchip.com/en-us/product/lan9252)、[SPI 评估方案](https://www.microchip.com/en-us/development-tool/evb-lan9252-spi)。具体板卡采用哪种接口和引脚，以商家原理图、EEPROM/PDI 配置与配套源码为准。

| 模拟器概念 | 迁移时对应的工作 |
|---|---|
| 本地字节数组 | 真实 ESC 过程数据访问接口 |
| FMMU/SM 教学配置 | 由真实 ESC、协议栈与主站建立的映射/通道 |
| 手工接收条件 | 新过程数据事件、长度和接收时间判断 |
| 普通 C 循环 | 真实周期事件与可测量执行预算 |
| JointModel | 电机控制接口、传感器与实际控制算法 |
| 模拟故障 bool | 实际故障检测与经过验证的保护机制 |

## 3. 为什么新 13 字节布局不能直接拿去上板

第十二课只约定应用层字节布局。真正迁移时，要让对象类型、PDO Mapping/Assignment、SM 长度、ESI 声明和主站 Process Image 一致，并确认设备支持相应模式。旧六字节与新十三字节是两个独立教学版本，不能只换 C 结构体就认为配置已同步。

新的字段没有进入旧字典/SDO，实际协议栈需要真正提供它们及访问权限。厂商的 CiA402 实现可能有额外运行条件与选项，应查设备手册，不能把本模拟器的固定 Option Code 2 当成所有驱动默认值。

## 4. 练习与参考答案

问题：主站看到 OP 是否就说明电机已经能运行？——不说明。OP 是通信状态，还要看 CiA402 状态、运行模式和实际本地运行条件。

问题：板卡上一次正常后，改 PDO 字节数却进不了 OP，先查什么？——对照固件、ESI、实际映射和 SM 长度；不要只看结构体成员或重试烧写。

问题：桌面模拟器通过，简历可以写“实现真实 1 ms EtherCAT 关节控制器”吗？——目前不可以。应写软件仿真、已实现模块和已验证行为；真实通信、周期测量和电机控制完成后再增加对应表述。
