## 本项目当前定位

**EtherCAT 从站数据通路与 CiA402 状态机软件仿真。** 软件学习阶段收尾，保留标准 C 程序、中文课程、流程图、练习记录、验证代码和 Git 版本。

第一至第五课为已学理论；第六至十一课有完课归档；第十二、十三课参考实现与材料已经生成，尚未记录学习者独立完课。个人已记录的练习包含位置数值、Rx 本地地址 0x1020、状态字样例 0x0023、使能条件 false。

工程中存在新的 `EtherCAT_Hardware_Project` 目录，其来源清单注明 `hardware_validation: not performed`。本次没有接线、刷写、扫描或对该目录做验收，不把它并入已验证课程或简历成果。原板卡迁移安排继续暂缓。
